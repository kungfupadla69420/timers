# Таймеры

Одностраничное табло: сколько осталось до событий и сколько прошло с них.
Один самодостаточный `index.html` — ни бэкенда, ни сборки, ни внешних запросов.

Опубликовано: https://kungfupadla69420.github.io/timers/

## Админка

Добавить `#admin` к адресу. Режим запоминается в `localStorage`, так что
второй раз хвост набирать не нужно; кнопка «Выйти» его снимает.

Пока не нажата «Опубликовать», правки — неопубликованный черновик в твоём
браузере; подпись в подвале об этом говорит прямо.

**«Опубликовать»** записывает список в `timers.json` через GitHub API и снимает
черновик. Посторонний увидит новый список примерно через полминуты — столько
живёт кэш API. Первый раз кнопка попросит токен.

**«Ссылка»** — разовый снимок: список зашит прямо в адрес (`#t=…`), ничего не
публикует. Годится, чтобы показать набор, не трогая общий список.

«Сброс» выбрасывает черновик и возвращает опубликованный список.
Пустой список — тоже сохраняемое состояние: удалил всё, и после перезагрузки
останется пусто, а не вернутся заглушки.

### Токен

Нужен тонкий (fine-grained) токен: доступ только к репозиторию `timers`,
право `Contents: Read and write`, срок по вкусу. Хранится в `localStorage`
этого браузера и уходит только на `api.github.com`. Если его украдут,
испортить смогут только это табло. При ответе 401 страница сама сотрёт
токен и попросит новый.

Ключ остаётся на устройстве, пока не нажмёшь «Выйти» — она уносит и флажок
админа, и ключ. Подпись в подвале говорит, лежит ли ключ здесь. На чужом
компьютере админку лучше не включать вовсе.

Сама админка — не замок: кто угодно может дописать `#admin` и увидеть
кнопки. Это ничего не даёт — правки останутся в его браузере, а публикация
требует ключа.

## Откуда берётся список

1. `#t=…` в адресе — снимок из ссылки, сеть не трогаем;
2. локальный черновик, если он есть;
3. `timers.json` из репозитория через contents API;
4. запасной вариант — `raw.githubusercontent`, если упёрлись в лимит API
   (60 запросов в час на человека);
5. вшитый в страницу `DEFAULTS`, если молчат оба.

Читаем именно через API, а не через raw: у raw кэш до пяти минут и не
сбрасывается уникальным query-параметром, у API — 60 секунд. Запрос идёт
без своих заголовков, иначе браузер потребует preflight.

## Как считается

У таймера только дата и, по желанию, время. Дата в будущем — секция «До»,
в прошлом — «Прошло с», переключается само в момент перехода.
Меньше суток — вместо числа дней встаёт `ЧЧ:ММ:СС`.
Человеческий пересчёт («1 год 9 месяцев») появляется только от года и выше,
где счёт в днях перестаёт укладываться в голове.

Дата события — это последний день, когда оно ещё было: «Матвей последний раз
в Минске» стоит на 21 октября, хотя 22-го его там уже не было. Так число под
датой сходится с самой датой.

## Устройство

Цифры набраны моноширинным (это измерение), названия — антиквой (это люди
и места). Разряды числа — окна над полосой `0..9`, которая при открытии
страницы прокручивается и защёлкивается на своей цифре.

Верное значение всегда стоит в базовом стиле, а прокрутка — надстройка:
если кадров не будет (скрытая вкладка, `prefers-reduced-motion`), число
всё равно показано правильно. Полоса помечена `aria-hidden`, голосу
отдаётся отдельное число.

Константа `CELL` в скрипте обязана совпадать с `--cell` в стилях.
