# Таймеры

Одностраничное табло: сколько осталось до событий и сколько прошло с них.
Один самодостаточный `index.html` — ни бэкенда, ни сборки, ни внешних запросов.

## Админка

Добавить `#admin` к адресу — или трижды кликнуть по точке `·` в подвале.
Режим запоминается в `localStorage`, кнопка «Выйти» его снимает.

Правки живут только в твоём браузере, пока не сделаешь одно из двух:

- **«Ссылка»** — копирует адрес с зашитым списком (`#t=…`). Кинул друзьям — они видят твой набор. У старой ссылки останется старый список.
- **«JSON»** — копирует список. Вставить в массив `DEFAULTS` в `index.html`, закоммитить — и опубликованное табло обновится для всех.

«Сброс» выкидывает локальные правки и возвращает то, что лежит в `DEFAULTS`.

## Как считается

У таймера только дата (и опционально время). Дата в будущем — секция «До»,
в прошлом — «Прошло с», переключается само в момент перехода.
Меньше суток — вместо числа дней встаёт `ЧЧ:ММ:СС`.
